## Установка / Install

- **Windows**: скачай и запусти **[clop Setup 2.5.0.exe](clop%20Setup%202.5.0.exe)**
- **Linux**: скачай [clop-2.5.0.tar.gz](../../releases/download/v2.5.0/clop-2.5.0.tar.gz), распакуй и запусти `./clop`

Свежие версии — в [Releases](../../releases).

## Возможности / Features

- **Чат как в Claude** — полноэкранный чат, боковая панель с историей, дизайн «жидкое стекло» с анимированным фоном
- **Свой ИИ на выбор**:
  - **Claude Code** (работает твоя подписка) с выбором модели: Fable 5, Opus 5, Sonnet 5, Haiku 4.5 и др.
  - любые **OpenAI-совместимые API**: несколько провайдеров сразу, до 128 моделей на каждого, свой макс. контекст у модели
  - **локальные модели через Ollama** — без API-ключа
- **Слайдер уровня раздумий**, свой для каждой модели — как в самом Claude Code: Low/Medium/High/Extra/Max/Ultracode на Sonnet 5, Opus 5 и Fable 5, урезанный набор на Sonnet 4.6, скрыт для Haiku 4.5
- **Настоящий агент** — живой поток раздумий как в Claude Code, лог действий с временем и токенами, кнопка «Стоп», очередь сообщений, параллельные чаты
- **Режим Коворк** — модель получает полный доступ к ПК: абсолютные пути, создание папок, запуск любых команд, открытие файлов/ссылок результатом
- **Слэш-команды** — `/clear`, `/rename`, `/cowork`, `/terminal`, `/git`, `/artifacts`, `/settings` и другие прямо в поле ввода
- **Индикатор контекста** — видно, насколько заполнено окно модели
- **11 CLI-агентов в один клик** — Claude Code, Codex, Gemini, Qwen Code, Kimi Code, GLM, OpenCode, GitHub Copilot CLI, Amp, Grok CLI, iFlow: не установленные ставятся кнопкой «Установить»
- **Оформление** — светлая и тёмная темы, 5 шрифтов, 4 размера текста, 6 цветов акцента
- **IDE-панель** — дерево файлов, редактор с вкладками, встроенный терминал PowerShell, вкладка Git (статус, дифф, коммит в один клик)
- **Артефакты** — созданные агентом файлы с живым предпросмотром HTML/картинок и историей версий с откатом
- **Агент задаёт вопросы** — карточки с кнопками вариантов прямо в чате
- **Источники** — просмотренные агентом веб-страницы кликабельны под ответом
- **100+ интеграций (MCP)** — GitHub, Notion, Slack, Stripe, Postgres, Figma, Playwright и десятки других; тысячи приложений через Zapier / Composio / Pipedream; любой свой MCP-сервер
- **Настройки страницами** — мини-боковушка: Общие / Оформление / Провайдеры / Агенты / Интеграции
- **Уровни разрешений** — авто / по разрешениям / всё разрешено
- **50 языков интерфейса**, английский по умолчанию
- Чаты и настройки переживают обновления (автобэкап)
